# Folder instructions

## Tag: Code and architecture (`code`)

This folder holds the Rive refresh header (`CYLRefreshRiveHeader`, `CYLRefreshRiveStyle`), a CYLRefresh control
compiled by the `Rive` subspec because it needs `RiveRuntime`; the Core subspec compiles only the `.h` / `.m` files of
`CYLRefresh/`. It inherits the vault's root instructions.
