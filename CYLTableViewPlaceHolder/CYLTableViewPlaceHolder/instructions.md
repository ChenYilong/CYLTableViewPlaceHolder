# Folder instructions

## Tag: Code and architecture (`code`)

This folder contains the placeholder component's public headers,
implementation, resource bundle, and third-party attribution. It inherits the
repository and vault instructions.

The resource bundle `CYLTableViewPlaceHolder.bundle` always contains the project's `LICENSE` (a copy of the root
`LICENSE`) next to the third-party licenses, because it ships in every CocoaPods and Carthage build; see "License in
every published package" in the root `instructions.md` and the `cyl-package-licenses` skill.
